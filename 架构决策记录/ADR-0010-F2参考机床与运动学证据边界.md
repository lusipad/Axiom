# ADR-0010：F2 参考机床与运动学证据边界

> 状态：Accepted
> 日期：2026-08-11
> 修订：2026-08-11
> 影响范围：FiveAxisTrajectoryPack M2～M3、MachineProfile、Reference Solver、Web UI

## 背景

Math F2 必须让两个独立实现对同一台数学机床得到相同的正运动学、逆运动学候选、wrap、限位、分支和奇异性结论。仅使用“双转台”“头转台”“双摆头”等名称不足以定义机床；轴序、安装侧、局部轴向、旋转中心、零位、符号、限位和刀具固定变换都会改变结果。

首版参考系统面向轴对称五轴铣削，任务姿态是单位刀轴，不要求绕刀轴的 roll。它需要三类可解析交叉验证基准，同时允许非正交、带偏置的显式 Profile 进入数值 IK，但不得把数值搜索未找到解解释成严格无解。

## 决策

1. 权威机器对象为 `five-axis.machine-profile@1`。每根轴显式记录运动类型、安装侧、同侧父子顺序、局部方向、局部轴线原点、零位、方向符号、单位、限位、周期性和语义角色；所有字段参与内容身份。首版 Profile 统一把直线量归一化为 `mm`、旋转量归一化为 `rad`，刚体变换四元数顺序固定为 `[x,y,z,w]`。跨轴聚合的限位裕量使用无量纲归一化距离 `min(q-lower, upper-q)/(upper-lower)`，取值范围为 `[0,0.5]`，不得把 `mm` 与 `rad` 直接取最小值。
2. 通用正运动学固定为 `T_WT(q) = T_W(q_W)^-1 T_T(q_T) T_tool`。轴变换按各自安装侧的声明顺序右乘；旋转轴方向和原点位于其父坐标系，直线轴沿父坐标系方向移动。不得由轴名推断顺序或安装侧。
3. F2 的三个版本化解析参考 Profile 统一使用毫米和弧度、单位固定变换、零轴线偏置、零位偏置 `0`、方向符号 `+1`、`X/Y/Z` 限位 `[-500, 500] mm`、倾斜轴限位 `[-2π/3, 2π/3]`、周期旋转轴限位 `[-2π, 2π]`，并使用 `T_tool.translation = [0, 0, -100] mm`：
   - `five-axis.machine-profile.canonical-table-table-ac@1`：工具侧 `X → Y → Z`；工件侧 `A(+X) → C(+Z child)`。零偏置刀轴为 `o = [sin(C) sin(A), cos(C) sin(A), cos(A)]`。
   - `five-axis.machine-profile.canonical-head-table-workpiece-c-tool-b@1`：工件侧 `C(+Z)`；工具侧 `X → Y → Z → B(+Y)`。刀轴为 `o = [cos(C) sin(B), -sin(C) sin(B), cos(B)]`。
   - `five-axis.machine-profile.canonical-head-head-cb@1`：工具侧 `X → Y → Z → C(+Z) → B(+Y)`；工件侧无运动轴。刀轴为 `o = [cos(C) sin(B), sin(C) sin(B), cos(B)]`。
4. 闭式 IK 必须枚举两组姿态分支和限位内的全部周期 wrap，随后以 Profile 轴序、连续轴值、wrap 向量和稳定 branch ID 做确定排序。奇异姿态保留为显式退化分支，不能用任意默认旋转角伪装成唯一解。
5. 每个候选必须用同一通用 FK 回代，分别记录位置残差、刀轴角残差、限位余量、wrap、分支族、Jacobian 最小奇异值或等价解析奇异性证据。闭式公式与通用链不一致属于执行失败，而不是不可支持能力。
6. 一般 Profile 使用固定 seed 集、固定残差尺度、固定去重/tie-break 的数值 IK。成功候选最高先标为 `Validated`；未收敛只能得到 `Inconclusive`，除非另有严格无解证书。
7. `KinematicallyFeasible` 断言的是整条 M2 路径存在满足回代、限位、分支连续和声明正则性的 M3 提升，单个姿态或有限不带区间界的采样不能支持该 Claim。
8. `ConfigurationCollisionFree` 需要独立的 `Q_free` 连续证书。F1 的 `TaskGeometryCollisionFree`、M3 的运动学回代和轴限位均不能替代该证书；F2 仍禁止设备安全、过程安全或不加限定的可执行声明。
9. M3 轴段统一以局部参数 `t=(sigma-sigmaStart)/(sigmaEnd-sigmaStart)` 的 `local-power@1` 幂基存储，`q(t)=Σ coefficients[k]t^k`。`linear` 必须有 2 个系数向量，`cubic-hermite` 必须先转换为 4 个幂基系数向量；没有 degree/knot 的裸系数不得标记为 B-spline。轴段系数必须精确回放其首尾 `IKSolution`。
10. 参与 M3 内容身份的 SVD 派生最小奇异值和条件数，按十进制 12 位有效数字、round-to-nearest/ties-to-even 规范化；奇异阈值判断仍使用规范化前的原始 binary64 值，证据量化不得改变能力或 Claim 状态。证书记录 `ieee-754-binary64` 和版本化数值证据策略，不记录具体 Python/NumPy 版本。具体运行时版本只进入 MathStageManifest 与 RunBundle 数值环境，使 M3/M4/M5 内容身份可跨受支持环境重放，同时让完整运行身份继续诚实绑定环境。

## 被否决方案

- **用 DH 参数表作为唯一机器语义**：可以表达部分串联链，但会隐藏工件侧/工具侧拆分、轴线安装侧和 Profile 固定变换。
- **每个拓扑只返回一个 IK 解**：会丢失姿态分支和周期 wrap，使路径连续性依赖隐藏初值。
- **把数值优化失败解释成无解**：局部求解器失败不能证明集合为空。
- **把厂商机床参数作为首版基准**：会把参考真值绑定到许可、后处理器约定和不可公开的装配细节。
- **用 F1 夹具碰撞满足 M3 碰撞 Claim**：任务空间工具几何没有覆盖移动机床部件和机构自碰撞。

## 后果

- 三类解析机床成为通用运动链和 IK 的交叉验证 oracle；以后新增真实 MachineProfile 不改变已有结果。
- F2 可以逐步增加一般数值 IK、连续分支图和配置空间碰撞，同时保持证据等级诚实。
- Web UI 必须显示 Profile 内容身份、分支/wrap、限位余量、回代残差和奇异性状态，并继续显示 `NOT DEVICE SAFE`。
- 若改变任一 canonical Profile 的轴序、方向、零位、限位或几何参数，必须发布新的 Profile ID；不得静默覆盖 `@1`。
