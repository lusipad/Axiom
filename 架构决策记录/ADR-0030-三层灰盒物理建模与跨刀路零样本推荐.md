# ADR-0030：三层灰盒物理建模、正交误差分解、跨刀路零样本推荐与 R0–R7 治理桥接

- 状态：Accepted
- 日期：2026-11-11
- Supersedes：[ADR-0029](ADR-0029-高维CNC参数质量评估与稀疏推荐闭环.md) 中的纯黑盒 `ElasticNet` 两阶段多项式代理部分
- 范围：`src/axiom/benchmark.py`、`src/axiom/greybox_model.py`、`src/axiom/parameter_space.py`、`src/axiom/parameter_learner.py`、`src/axiom/parameter_recommender.py`、`src/axiom/cnc_governance.py`

## 背景与问题

`ADR-0029` 首版使用两阶段纯黑盒回归（`ElasticNet` 线性+纯二次筛选 + 活跃子空间二阶响应面）拟合 32 维 CNC 参数，且与仓库既有的 `R0–R7` 证据治理主干（`DomainPack` / `RunBundle` / `Claim`）相互独立。在真实 CNC 速度规划与伺服控制场景下暴露出五项核心问题：

1. **硬取小死区失真与无关轴幻觉**：真实前瞻、向心限速与单轴限幅遵循硬取小 `min(...)` 包络，存在宽广的平坦饱和死区；小样本二阶多项式在死区产生伪拐点与抛物线回弯，并在高维欠定条件下将物理无关参数（如纯 XY 刀路上的 Z 轴速度/加速度上限）误判为活跃参数；
2. **已知解析物理规律浪费实机样本**：圆弧插补后滤波内缩（FIR `sinc` $\times$ Butterworth）、拐角滤波后速度谷值平滑、稳态速度前馈滞后与双轴增益失配本身具有精确解析形式，用纯黑盒去猜物理定律严重浪费稀缺的实机占机采样；
3. **法向轮廓误差带符号相消盲区**：规划内缩（指向曲率中心内侧）与伺服惯量外摆（指向曲率中心外侧，含切向滞后二阶曲率修正项 $-(\bar{c}_a + \frac{1}{2}\bar{c}_v^2)a_{\text{norm}}$）在法向空间发生带符号叠加或抵消，标量直接相加会产生系统偏差；
4. **单刀路死绑定**：回归权重耦合了单一校准刀路的几何常数，无法将在标准试件上标定的控制器/机床画像零样本迁移到新零件 NC 程序；
5. **双主干割裂**：外部 CNC 参数优化闭环未能复用 `R3` 只读遥测接入与 `R4–R7` 证据封存声明体系。

## 决策

1. **升级 `benchmark.py` 单次评估底座**：引入 $O(N+M)$ 单调弧长进度游标与局部 Frenet 标架，将伺服跟踪误差正交分解为切向相位滞后（`tangentialLagMaxMm`）与法向伺服误差（`normalServoErrorMaxMm`），增加圆弧带符号径向偏移均值（`signedRadialOffsetMeanMm`）、周期无关的物理弧长拐角切片、7 点三次 Savitzky-Golay 抗噪 Jerk（`smoothedJerkRmsMmS3`）以及有符号法向残差 Hanning-FFT 结构谐振主频辨识（`dominantResonanceFreqHz`、`resonanceBandRmsMm`）。
2. **新增 `greybox_model.py` 三层灰盒物理引擎**：
   - **第一层（白盒解析物理核）**：对任意三维/平面 `CncBenchmarkCase` 提取零轨迹几何画像，解析计算分段硬取小速度包络、前后向加减速传播、拐角滤波谷值卷积、圆弧滤波内缩、级联 P-PI 伺服滞后及二阶曲率-延迟法向矢量叠加；
   - **第二层（受约束机理常数标定）**：通过时序有界最小二乘 `lsq_linear` 闭式辨识各轴速度环等效带宽比，并用有界信赖域反射 `least_squares` 联合标定样条曲率系数、前瞻安全裕度、拐角谷值平滑系数与静摩擦脱开基准；
   - **第三层（低维最大边缘似然 ARD-GP 残差核与 LOCO 留一验证）**：剥离灰盒主干后，在 3～6 维紧凑物理特征子空间上以 `L-BFGS-B` 最大化边缘似然训练 Matérn-5/2 GP，输出异方差自适应 Split Conformal 安全上界，并在多工况训练时自动生成跨刀路留一验证报告（`CrossToolpathValidationSummary`）。
3. **正交灰盒定参 DoE 与新零件零样本稀疏推荐**：在 `parameter_space.py` 提供 `orthogonal-greybox` 正交物理激励锚点表（10 组离线 + 6 组实机即可定参），在 `recommend_parameters` 支持传入任意未见零件 `target_case`，结合谐振陷波零点对齐（$T_{\text{FIR}} = 1000/f_{\text{res}}$、$f_{\text{notch}} = f_{\text{res}}$）输出三档差异化 Pareto 稀疏微调方案。
4. **新增 `cnc_governance.py` 打通 `R0–R7` 治理主干**：注册 `cnc-greybox.domain-pack@1` 与 `cnc.export-to-ordered-point@1` 适配器，提供 R3 只读遥测转 CNC 导出桥接及四层封存声明（L0 硬限、R4 灰盒标定、R5 适用域与保形区间、R7 零写入 `OfflineAdvisory` 边界）。
