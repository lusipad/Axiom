# ADR-0030：三层灰盒物理建模、正交误差分解、跨刀路零样本推荐与 R0–R7 治理桥接

- 状态：Proposed（2026-11-12 评审后由 Accepted 退回，见文末“评审修订”）
- 日期：2026-11-11；修订：2026-11-12
- Supersedes：[ADR-0029](ADR-0029-高维CNC参数质量评估与稀疏推荐闭环.md) 中的纯黑盒 `ElasticNet` 两阶段多项式代理部分
- 范围：`src/axiom/benchmark.py`、`src/axiom/greybox_model.py`、`src/axiom/parameter_space.py`、`src/axiom/parameter_learner.py`、`src/axiom/parameter_recommender.py`、`src/axiom/cnc_governance.py`

## 背景与问题

`ADR-0029` 首版使用两阶段纯黑盒回归（`ElasticNet` 线性+纯二次筛选 + 活跃子空间二阶响应面）拟合 32 维 CNC 参数，且与仓库既有的 `R0–R7` 证据治理主干（`DomainPack` / `RunBundle` / `Claim`）相互独立。在真实 CNC 速度规划与伺服控制场景下暴露出五项核心问题：

1. **硬取小死区失真与无关轴幻觉**：真实前瞻、向心限速与单轴限幅遵循硬取小 `min(...)` 包络，存在宽广的平坦饱和死区；小样本二阶多项式在死区产生伪拐点与抛物线回弯，并在高维欠定条件下将物理无关参数（如纯 XY 刀路上的 Z 轴速度/加速度上限）误判为活跃参数；
2. **已知解析物理规律浪费实机样本**：圆弧插补后滤波内缩（FIR `sinc` $\times$ Butterworth）、拐角滤波后速度谷值平滑、稳态速度前馈滞后与双轴增益失配本身具有精确解析形式，用纯黑盒去猜物理定律严重浪费稀缺的实机占机采样；
3. **法向轮廓误差带符号相消盲区**：规划内缩（指向曲率中心内侧）与伺服惯量外摆（指向曲率中心外侧，含切向滞后二阶曲率修正项 $-(\bar{c}_a + \frac{1}{2}\bar{c}_v^2)a_{\text{norm}}$）在法向空间发生带符号叠加或抵消，标量直接相加会产生系统偏差；
4. **单刀路死绑定**：回归权重耦合了单一校准刀路的几何常数，无法将在标准试件上标定的控制器/机床画像零样本迁移到新零件 NC 程序；
5. **双主干割裂**：外部 CNC 参数优化闭环未能复用 `R3` 只读遥测接入与 `R4–R7` 证据封存声明体系。

## 决策

1. **升级 `benchmark.py` 单次评估底座**：引入 $O(N+M)$ 单调弧长进度游标与局部 Frenet 标架，将伺服跟踪误差正交分解为切向相位滞后（`tangentialLagMaxMm`）与法向伺服误差（`normalServoErrorMaxMm`），增加圆弧带符号径向偏移均值（`signedRadialOffsetMeanMm`）、周期无关的物理弧长拐角切片、7 点三次 Savitzky-Golay 抗噪 Jerk（`smoothedJerkRmsMmS3`）以及有符号法向残差 Hanning-FFT 结构谐振主频辨识（`dominantResonanceFreqHz`、`resonanceBandRmsMm`）。
2. **新增 `greybox_model.py` 三层灰盒物理引擎**：
   - **第一层（白盒解析物理核）**：对任意三维/平面 `CncBenchmarkCase` 提取零轨迹几何画像，解析计算分段硬取小速度包络、前后向加减速传播、拐角滤波谷值卷积、圆弧滤波内缩、级联 P-P（位置 P + 速度 P，含速度/加速度前馈）伺服稳态误差展开及二阶曲率-延迟法向矢量叠加；
   - **第二层（受约束机理常数标定）**：通过时序有界最小二乘 `lsq_linear` 闭式辨识各轴速度环等效带宽比，并用有界信赖域反射 `least_squares` 联合标定样条曲率系数、前瞻安全裕度、拐角谷值平滑系数与静摩擦脱开基准；
   - **第三层（低维最大边缘似然 ARD-GP 残差核与 LOCO 留一验证）**：剥离灰盒主干后，在 3～6 维紧凑物理特征子空间上以 `L-BFGS-B` 最大化边缘似然训练 Matérn-5/2 GP，输出留一残差分位数不确定性半径（仅在留一误差优于纯灰盒时启用残差 GP），并在多工况训练时自动生成跨刀路留一验证报告（`CrossToolpathValidationSummary`）。
3. **正交灰盒定参 DoE 与新零件零样本稀疏推荐**：在 `parameter_space.py` 提供 `orthogonal-greybox` 物理激励锚点表（手选单因素锚点，并非正交表）（10 组离线 + 6 组实机即可定参），在 `recommend_parameters` 支持传入任意未见零件 `target_case`，结合谐振陷波零点对齐（$T_{\text{FIR}} = 1000/f_{\text{res}}$、$f_{\text{notch}} = f_{\text{res}}$）输出三档差异化 Pareto 稀疏微调方案。
4. **新增 `cnc_governance.py` 打通 `R0–R7` 治理主干**：注册 `cnc-greybox.domain-pack@1` 与 `cnc.export-to-ordered-point@1` 适配器，提供 R3 只读遥测转 CNC 导出桥接及四层封存声明（L0 硬限、R4 灰盒标定、R5 适用域与保形区间、R7 零写入 `OfflineAdvisory` 边界）。

## 评审修订（2026-11-12）

评审发现首版的验证依据是自证的：`simulate_realistic_cnc_controller` 与灰盒核共用同一套公式和常数，测试与治理都以它为真值。把仿真器隐含常数和速度环结构稍作改动后，伺服侧推荐结论会反转；伺服层“物理常数”贴边界且与真值无关；不确定性半径经启发式缩放后 4/4 未覆盖；治理 Claim 直接读取调用方自报字段，可被篡改。规划侧周期迁移（2–4% 误差）在两套真值下都成立。

据此做出以下修订（同一分支的后续提交）：

1. **声明降级**：`cnc-greybox.r4-*` / `r5-*` 是关于真实机床的声明，在接入实机验证数据（预测台账）之前一律 `Inconclusive`（`RealMachineHoldoutRequired`），证据等级统一为 `Observed`，不再使用 `Validated`；与 [ADR-0015](ADR-0015-R4轴空间物理模型与SIL可信度边界.md)、[ADR-0017](ADR-0017-R5B-Windows真实holdout就绪门边界.md) 的合成数据边界对齐。仅有合成数据时 Run 的 caseOutcome 不会是 `Passed`。
2. **防篡改**：治理评估重算 surrogate 与推荐报告的内容哈希，并检查报告绑定的 surrogate 哈希；不一致返回 `ContentHashMismatch`。模型拟合度指标改为留一 R²（`cnc-greybox.surrogate-mean-loo-r2@1`）。
3. **R3 桥接**：校验 `traceContentHash`、`deviceTimestamp` 步长与案例采样周期一致（默认 ±10%）、拒绝 `bad`/`suspect` 通道（可显式放行 suspect），实测通道必须全有或全无。
4. **学习器**：残差 GP 仅在留一 RMSE 低于纯灰盒 RMSE 的 98% 时启用（`residualEnabled`）；不确定性半径为留一残差在秩 ⌈(n+1)(1−α)⌉ 的分位数，不再按后验方差或量级缩小，越出包络时放大；对未参与标定的刀路，用 LOCO 最差零样本误差 ×1.645 作为下限；特征包络改为训练数据真实范围（取消强制 ±0.95）；伺服/规划系数注明为拟合系数，贴边界的系数显式标注“不可辨识”。
5. **参数注册表**：校验 `registryContentHash`；注册表缺少灰盒核（`generic-fir-biquad@1`）所需参数时直接报错，导出中含注册表以外的参数也报错，不再静默回退默认值。
6. **推荐器**：删除手写候选（含进给倍率 1.18–1.20），仅保留由 FFT 实测谐振频率推导的 FIR/陷波对齐种子；进给倍率默认上限 1.0（`maximumFeedOverride`）；随机候选只在训练包络内采样；没有可行候选时不输出档位并给出 `noFeasibleReason`（含主要失败门禁）；三档去重；修复无 jerk 上限与缺少指标头时的崩溃。
7. **评估底座**：`quadrantGlitchMaxMm` 恢复原口径（换向 ±5 采样内实测轮廓误差最大值），新口径另立为 `quadrantGlitchExcessMm`（扣除指令偏差、约 15 ms 窗口），灰盒模型改用新指标；恢复模块中关于有限差分“诊断而非证书”的边界说明。

尚未解决（后续工作）：控制器画像 / 通用物理量层（换数控厂商）、对抗仿真库（结构失配的仿真真值）、预测台账与实机对账、伺服常数的时序可辨识性检验、仿真器自身缺陷（微小段 Y 坐标缩放、与运动无关的谐振激励）。在这些完成之前，本 ADR 保持 Proposed。
