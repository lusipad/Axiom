# ADR-0037：R5-I 本机模型生命周期与设备部署隔离

- 状态：Accepted
- 日期：2026-08-14
- 决策范围：独立模型晋升决定、本机持久化 Registry、默认模型切换、监控与显式回滚边界

## 背景

R5-G 已冻结可交独立审查的候选证据，R5-H 也能在外部提交完整现场证据时形成只限预登记 Case 的 `CaseScopedPassed`。但这两项证据都刻意不改变默认模型。真正采用候选还缺少独立决定、可验证授权、持久化注册、原子默认切换、提交后读回、运行监控和可执行回滚。

模型采用也不能等同设备部署。当前仓库没有 PLC 下载、控制器参数写入、受控试验授权或设备安全证明；若让网页按钮或内存变量直接“激活”候选，会同时跳过治理、崩溃恢复和权限隔离。

## 决策

1. 新增 Windows-only R5-I 应用层合同。它只管理 Axiom 本机纯 Python `ConditionalEffectModelBundle` 的默认读取指针，不新增 DomainPack，不修改 Core，也不连接 CNC 或控制器。
2. 晋升必须同时提交可权威重放的 R5-G dossier、`Passed + CaseScopedPassed` 的 R5-H assessment，以及独立 `PromotionDecision`。决定必须绑定 dossier、holdout assessment、候选和冻结回滚基线的内容身份；决定人不得是 R5-G 准备人。
3. 首版授权证明使用调用方注入的 HMAC-SHA256 key provider。密钥不得进入请求、响应、SQLite、网页或日志；该机制只形成单机内容绑定，不声称企业级不可否认性。后续 PKI 必须以版本化 proof 替换，而不改变决定主体。
4. Registry 使用显式路径的本地 SQLite，不增加依赖，不接受内存数据库、文件 URI 或 UNC 网络共享。模型、授权、默认指针、generation、事件和监控窗口持久保存；外键、WAL、同步提交和 busy timeout 明确开启。
5. 候选注册、默认指针切换、generation 增长和 ActivationReceipt 必须在同一事务内完成。事务后重新读回 model hash 与 generation；决定重放幂等，相同 ID 不同内容、generation 冲突、半写或读回不一致全部 fail closed。
6. 运行监控绑定 Registry identity、默认 bundle 和 generation，分别检查 bundle 完整性、推理完整性、OOD、两个独立目标的 RMSE 与区间覆盖。状态固定为 `Healthy | Open | RollbackRequired`，不合成总分，也不产生 DeviceSafe、ProcessSafe 或工艺质量结论。
7. 首版禁止自动回滚。只有已持久化的 `RollbackRequired` 监控报告才能触发独立签名的显式 rollback transaction；目标只能是 R5-G 冻结的 baseline，并产生新 generation 与读回回执。
8. 所有有状态操作只由 Windows 本机 `axiom model-lifecycle` CLI 执行，并要求显式 Registry 路径。HTTP/网页只提供 manifest、预检、状态、监控列表和当前默认模型推理；OpenAPI 不提供 promote、activate 或 rollback 路由。
9. `modelPromotionStatus=Performed` 只表示本机 Registry 已切换默认模型。`automaticDeploymentAllowed=false`、`deviceWriteAllowed=false`、Deployment Shadow、Controlled Trial、Closed Loop 与设备安全门始终不因 R5-I 关闭。

## 后果

- 候选采用从证据准备、真实 Case 验证、独立决定、持久化切换、监控和回滚形成可审计的逐门链路。
- 进程重启后仍能读回同一默认 bundle 和 generation；事务故障不会留下“已注册但未激活”或“已切换但无回执”的伪状态。
- 网页可以观察生命周期而不成为授权边界；拿到浏览器访问权不等于获得本机模型写权限。
- 当前实现仍不是集中式 Registry、企业审批系统、远程多机部署平台或 CNC 闭环控制系统。

## 被拒方案

- **R5-H 通过后自动晋升**：Case-scoped 证据不是独立治理决定，也不能授权状态变化。
- **用内存字典保存默认模型**：进程重启即丢失，无法提供事务、读回、冲突检测或恢复证据。
- **注册与默认切换分两次提交**：崩溃会留下不可解释的中间状态。
- **在网页提供晋升或回滚按钮**：当前 Web 没有认证、授权、CSRF 防护或可信操作者身份。
- **监控失败后自动回滚**：会把观测结论扩大成未经独立授权的写操作。
- **把模型激活解释为设备部署**：本机解释器指针不具备控制器权限、停止链或设备安全证据。
- **首版直接引入远程 Registry 或企业 PKI**：当前只有单机 Windows 生命周期需求，引入网络服务会扩大信任边界和依赖面。
